# النسخة 12 — فئات قابلة للتدريب وتعابير ظاهرة

## التحديث دون حذف المشروع
أغلق البرنامج. فك biometric_v12_update.zip داخل مجلدك الحالي C:\biometric_v10_auto_update ووافق على الاستبدال. احتفظ بـ .venv و.objects وyolov8n.pt. لا تحذف المجلد. ثم شغّل .\START_CAMERA.cmd. لا تحتاج مكتبات إضافية إذا كانت إضافة الأجسام مثبتة.

## ما أضيف
- فئات جاهزة للتجهيز: محفظة، مفتاح، كأس/كوب، هاتف. يمكن تغييرها قبل تعليم الصور.
- أداة محلية لإنشاء مجلدات الصور، رسم المربعات، التحقق من البيانات، ضبط YOLO، اختبار مستقل، ثم تفعيل اختياري للنموذج الناتج.
- الأوزان الحالية لا تعرف المحفظة والمفتاح تلقائيًا بمجرد هذا التحديث؛ تحتاج صورك المعلّمة وتشغيل التدريب.
- وصف إضافي لابتسامة عريضة محتملة، هبوط زوايا الفم، رفع حاجب واحد، عدم تماثل الفم، وتضييق العينين.
- لا تصنيف لـ29 حالة نفسية ولا كشف حب أو مكر أو كآبة. التفاصيل الكاملة في FACE_EXPRESSIONS_AR.md.

ابدأ تدريب الأغراض باتباع TRAIN_OBJECTS_AR.md. لا توجد صور تدريب مرفقة. نُفذت اختبارات برمجية للبيانات والمنطق، ولم يُنفذ تدريب كامل أو تقييم دقة لفئاتك لعدم توفر بياناتها.

الواجهة بلا قائمة منبثقة أو تظليل سفلي. الرمش واليد والتعابير والتحقق تلقائيًا. لا يتفعل الميكروفون أو حفظ الصور تلقائيًا. بعض أدلة الإصدارات السابقة توثيق تاريخي.
